# CLAUDE.md

**Read [docs/SPEC.md](docs/SPEC.md) first — it defines what Bellboy is and what gets built.**
Bellboy is a messenger assistant that offers, starts and reports Claude Code cloud work across the
owner's GitHub projects, paced by their Claude usage limits.

**Work is taken from the [board](https://github.com/users/shoraLBRT/projects/4)** by the habze
order; [docs/ROADMAP.md](docs/ROADMAP.md) holds the stages and their exit criteria;
[docs/PROJECT_STATE.md](docs/PROJECT_STATE.md) says what exists and how to verify a change.

See [AGENTS.md](AGENTS.md) for how to work in this repository. The project follows the
[habze](https://github.com/shoraLBRT/habze) standard (version: none yet — habze S0 in progress).
